# Бие даан шалгах

Сонголт: **Ардчилсан оюутны чуулганы төлөөлөгчийн сонголт** (`2026-student-congress`). Өгөгдлийн сан, нууц түлхүүр, интернэт шаардлагагүй; зөвхөн [Node.js](https://nodejs.org) 18 буюу түүнээс шинэ хувилбар хэрэгтэй.

## Шалгах

Энэ хавтсыг (эсвэл бүх репозиторийг) татаж аваад:

```bash
cd verification
node verify.mjs            # бүх файл, хэш, дүнг офлайн шалгана
node verify.mjs --online   # нэмж Bitcoin блокийг хоёр нээлттэй explorer-тэй тулгана
```

`RESULT: PASS` гарвал нийтлэгдсэн дүн нь түгжигдсэн жагсаалт, мандатын хүснэгт болон Bitcoin блокийн хэшээс гарах цорын ганц боломжит дүн мөн.

## Файлууд

| Файл | Юу вэ | Хэзээ нийтэлсэн |
|---|---|---|
| `snapshot.json` | Түгжигдсэн жагсаалт (оролцогчийн дугаар, сургууль, хүйс) | Сонголтоос өмнө |
| `mandates.json` | Сургууль бүрийн мандат | Сонголтоос өмнө |
| `commitment.json` | Жагсаалт, мандатын хэш, нууц түлхүүрийн хэш | Сонголтоос өмнө |
| `verify.mjs` | Шалгах програм (нээлттэй эх код) | Сонголтоос өмнө |
| `manifest-commitment.json` | Сонголтоос өмнө нийтэлсэн файл бүрийн хэш | Сонголтоос өмнө |
| `proof.json` | Bitcoin блокийн толгой, нууц түлхүүр, нэр дэвшигч блокууд | Дүн зарласны дараа |
| `results.json` | Сонголтын дүн: сонгогдсон, нөөцийн дараалал (зөвхөн ID) | Дүн зарласны дараа |
| `manifest-results.json` | Дүнгийн файл бүрийн хэш | Дүн зарласны дараа |

## Анхаарах

Офлайн шалгалт нь блокийн толгойн proof-of-work болон дүрмийг шалгадаг боловч бүрэн Bitcoin node ажиллуулсантай тэнцэхгүй. Блок үндсэн сүлжээнд байгаа эсэхийг `--online` горим эсвэл өөрийн node-оор (`bitcoin-cli getblockhash <өндөр>`) нотолно.
