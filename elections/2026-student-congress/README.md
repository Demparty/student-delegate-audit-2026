## Сонголт хэрхэн явагдсан бэ

1. **Жагсаалтыг түгжсэн.** Бүртгүүлсэн оюутнуудын жагсаалт, сургуулийн мандатыг өөрчлөгдөхгүйгээр түгжиж, хэшийг тооцсон.
2. **Сонголтоос өмнө нийтэлсэн.** Энэ хавтсыг (жагсаалт, хэш) сонголт хийхээс өмнө нийтэлсэн тул дараа нь жагсаалтыг өөрчлөх боломжгүй.
3. **Санамсаргүй түүвэр.** Сонголтын өдөр олборлогдсон Bitcoin блокуудаас нэгийг сонгож хэшээр сургууль, хүйс бүрийн оюутнуудыг эрэмбэлж, мандатын тоогоор төлөөлөгч сонгосон. Бүртгэл нь мандатаас ихгүй бол бүгд шууд сонгогдоно.
4. **Дүнг нийтэлсэн.** Төлөөлөгчдийг танхимд зарласны дараа `selected/` хавтас болон дүнгийн файлуудыг энд нэмсэн. Өмнөх файлууд өөрчлөгдөөгүй.

## Хувийн мэдээлэл

Нийтийн файлд регистрийн дугаар, утасны дугаар байхгүй. Оюутныг санамсаргүй оролцогчийн дугаараар (ID) ялгаж, нэрийг товчилсон (жишээ нь «Б.Болд»).

## Бие даан шалгах

Дүн нь түгжигдсэн жагсаалт болон Bitcoin блокоос гарах цорын ганц боломжит дүн мөн эсэхийг хэн ч өөрөө шалгаж болно. Дэлгэрэнгүй заавар: [`verification/README.md`](verification/README.md).

```bash
cd verification
node verify.mjs
```

## Хязгаарлалт

Сонголтын өдөр: 2026-11-13 (Улаанбаатарын цаг). Тухайн өдөр, жагсаалт түгжсэний дараа олборлогдсон Bitcoin блокуудаас нэгийг сервер нууц түлхүүрээр сонгосон; түлхүүрийн хэшийг сонголтоос өмнө нийтэлсэн.

Нотлох боломжгүй зүйл: сервер блокуудын жагсаалтыг хэзээ царцаахаа өөрөө сонгосон тул өөр мөчид оролдоогүй, дүнг нуугаагүй гэдгийг энэ материал батлахгүй. Энэ нь урьдчилан зарласан ирээдүйн блокийн дүрэмтэй адил хүчтэй биш.
